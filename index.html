If your DAW doesn't see it

Downloaded plugins can carry a macOS quarantine attribute. For a build you trust, run the command below after replacing the example path with the actual location of the .vst3 or .component bundle. This removes that attribute; it does not guarantee that every DAW will detect or load the plugin.

sudo xattr -rd com.apple.quarantine /path/to/your/plugin
  1. 1

    Keep a space after com.apple.quarantine.

  2. 2

    Replace /path/to/your/plugin with the full path to your installed .vst3 or .component bundle. Dragging the bundle from Finder into Terminal inserts its path.

  3. 3

    Press Return, enter your Mac password if prompted, then restart your DAW and rescan its plug-ins (VST3 or Audio Units, depending on the format).

Example for the default user VST3 foldersudo xattr -rd com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/Phase Garden.vst3"

Use only if this is the actual location. Keep quotes around paths containing spaces.

Only remove quarantine from software you trust. If the plugin still does not appear, check the DAW's VST3 folder settings and rescan.
